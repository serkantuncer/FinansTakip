FinansTakip - Kurulum ve Build Rehberi

1) Sanal ortam oluşturma
python -m venv .venv

2) Sanal ortamı aktif etme
Windows (PowerShell):
.venv\Scripts\Activate.ps1

Windows (CMD):
.venv\Scripts\activate.bat

Linux/macOS:
source .venv/bin/activate

3) Bağımlılıkları kurma
.\.venv\Scripts\python -m pip install --upgrade pip
.\.venv\Scripts\python -m pip install -r requirements.txt

4) Uygulamayı geliştirme modunda çalıştırma
.\.venv\Scripts\python .\main.py

------------------------------------------------------------
Windows Build (Önerilen)

1) Temizleme
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue

2) Build bağımlılıklarını kur
.\.venv\Scripts\python -m pip install -r requirements-dev.txt

3) Build al
.\.venv\Scripts\python -m PyInstaller FinansTakip-Windows.spec --clean --noconfirm

4) Çıktı
.\dist\FinansTakipSistemi.exe

------------------------------------------------------------
macOS Build (macOS ortamında)

1) Temizleme
rm -rf build dist __pycache__

2) Build bağımlılıklarını kur
python -m pip install -r requirements-dev.txt

3) Build al
python -m PyInstaller FinansTakip-macOS.spec --clean --noconfirm

4) Çıktı
./dist/FinansTakipSistemi.app

5) Gerekirse dylib düzeltmesi
./postbuild_fix.sh

------------------------------------------------------------
Notlar

- Projedeki güncel spec dosyaları:
  - FinansTakip-Windows.spec
  - FinansTakip-macOS.spec

- Port doluysa kontrol:
  - macOS/Linux: lsof -i :5001
  - Windows PowerShell: netstat -ano | findstr :5001

- Port kapatma:
  - macOS/Linux: kill -9 $(lsof -t -i :5001)
  - Windows PowerShell: taskkill /PID <PID> /F
